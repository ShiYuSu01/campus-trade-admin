# 部署运行手册

> 本手册按“本机 Windows 11 + JDK 25 + Tomcat 11.0.22 + MySQL 8.0.46”编写。  
> 项目已经按本手册在本机完整启动验证过，访问地址：`http://localhost:8080/campus-trade-admin/`。

## 一、最快启动（推荐）

打开命令提示符（Win + R 输入 `cmd`），执行：

```bat
cd /d "D:\学校\java  ee\期末大作业\campus-trade-admin"
scripts\build.bat
scripts\start-server.bat
```

浏览器访问：

```text
http://localhost:8080/campus-trade-admin/
```

登录：

```text
账号：admin
密码：123456
```

停止：

```bat
scripts\stop-server.bat
```

> 第一次启动如果数据库不存在，项目会自动创建 `campus_trade` 库、6 张表并写入演示数据。  
> 如果数据库已存在，则跳过初始化，不会覆盖你的数据。

## 二、启动脚本做了什么

### `scripts\build.bat`

1. 切换到项目根目录。
2. 如果存在项目自带的 `.m2repo`，使用它作为 Maven 本地仓库，避免依赖下载和权限问题。
3. 执行 `mvn clean package -DskipTests`。
4. 生成 `target\campus-trade-admin.war`。

### `scripts\init-tomcat.ps1`

1. 在项目下创建独立 Tomcat 实例目录 `.tomcat`。
2. 从 `D:\apache-tomcat-11.0.22\conf` 复制默认配置。
3. 用 `scripts\tomcat-server.xml` 覆盖 `server.xml`，去掉原配置里的 `Struts2Demo` Context。
4. 复制 `catalina.bat` / `setclasspath.bat` 到 `.tomcat\bin`，删除硬编码的 `set JRE_HOME=D:\jdk`。
5. 把 WAR 复制到 `.tomcat\webapps`，并删除旧的解压目录，保证重新部署。
6. 本地脚本调用 `%CATALINA_BASE%\bin\setclasspath-local.bat`，使用 `JAVA_HOME`。

### `scripts\start-server.bat`

1. 设置：
   ```bat
   CATALINA_HOME=D:\apache-tomcat-11.0.22
   CATALINA_BASE=项目\.tomcat
   JAVA_HOME=D:\Program Files\Java\jdk-25.0.4.1
   JRE_HOME=%JAVA_HOME%
   CATALINA_OPTS=-Dfile.encoding=UTF-8
   ```
2. 调用 `init-tomcat.ps1`。
3. 调用 `.tomcat\bin\catalina-local.bat run`，前台启动，关闭窗口即停止。

### `scripts\stop-server.bat`

调用 `.tomcat\bin\catalina-local.bat stop`，通过 Tomcat 的 8005 关闭端口停止服务。

## 三、手动初始化数据库

项目支持自动初始化，但手动执行更直观：

```bat
scripts\init-db.bat
```

等价的 SQL 命令：

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p123456 --default-character-set=utf8mb4 < sql\schema.sql
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p123456 --default-character-set=utf8mb4 < sql\data.sql
```

检查：

```sql
USE campus_trade;
SHOW TABLES;
SELECT COUNT(*) FROM t_product;
```

预期：

```text
t_audit_log
t_category
t_order
t_product
t_report
t_user

14
```

### 修改数据库密码

编辑：

```text
src/main/resources/db.properties
```

```properties
jdbc.username=root
jdbc.password=你的密码
```

或者在启动 Tomcat 前设置环境变量：

```bat
set CAMPUS_DB_PASSWORD=你的密码
```

`DbUtil` 会优先读取 `CAMPUS_DB_URL`、`CAMPUS_DB_USER`、`CAMPUS_DB_PASSWORD`。

## 四、手动构建与部署（不使用脚本）

### 1. 构建

```bat
cd /d "D:\学校\java  ee\期末大作业\campus-trade-admin"
mvn clean package -DskipTests
```

如果依赖下载失败，使用项目本地仓库：

```bat
mvn "-Dmaven.repo.local=D:\学校\java  ee\期末大作业\campus-trade-admin\.m2repo" clean package -DskipTests
```

### 2. 部署 WAR 到独立 Tomcat 实例

```bat
set CATALINA_HOME=D:\apache-tomcat-11.0.22
set CATALINA_BASE=D:\学校\java  ee\期末大作业\campus-trade-admin\.tomcat
set JAVA_HOME=D:\Program Files\Java\jdk-25.0.4.1
set JRE_HOME=%JAVA_HOME%

copy target\campus-trade-admin.war "%CATALINA_BASE%\webapps\"
call "%CATALINA_BASE%\bin\catalina-local.bat" run
```

### 3. 部署到原 Tomcat（不推荐，需先清理全局配置）

本机 `D:\apache-tomcat-11.0.22\conf\server.xml` 末尾有一个残留的：

```xml
<Context docBase="D:\apache-tomcat-11.0.22\wtpwebapps\Struts2Demo"
         path="/Struts2Demo" reloadable="true" .../>
```

如果直接启动原 Tomcat，会因为它缺少 log4j 而启动失败。处理方式二选一：

1. **推荐**：使用本项目的 `.tomcat` 独立实例（`scripts\start-server.bat`）。
2. 如果一定要用原 Tomcat：先备份 `conf\server.xml`，删除上面的 `<Context ... Struts2Demo .../>`，再启动。注意不要破坏你其他课程项目。

另外，原 Tomcat 的 `bin\catalina.bat` 与 `bin\setclasspath.bat` 第 1 行硬编码了：

```bat
set JRE_HOME=D:\jdk
```

如果 `D:\jdk` 不是有效 JDK，会报 `JRE_HOME environment variable is not defined correctly`。可以改成你的 JDK 路径，或使用项目脚本生成的本地启动脚本。

## 五、IDEA 中运行与调试

### 1. 打开项目

`File → Open` 选择 `campus-trade-admin`，等待 Maven 导入。

### 2. 项目 SDK

`File → Project Structure → Project`：

- SDK：`25`（`D:\Program Files\Java\jdk-25.0.4.1`）
- Language level：`21`

### 3. Maven

`Settings → Build, Execution, Deployment → Build Tools → Maven`：

- Maven home：`D:\jdk\apache-maven-3.9.16`
- JDK for importer：25
- User settings file：`C:\Users\你的用户名\.m2\settings.xml`（已配置阿里云镜像）

### 4. Tomcat 配置（可选）

1. `Run → Edit Configurations → + → Tomcat Server → Local`。
2. Application server：`D:\apache-tomcat-11.0.22`。
3. Deployment：`+ → Artifact → campus-trade-admin:war exploded`。
4. Application context：`/campus-trade-admin`。
5. 启动。

> 如果 IDEA 使用全局 Tomcat 配置并再次遇到 `Struts2Demo` 启动失败，说明它读取了原 `conf/server.xml`。此时建议：
> - 用 `scripts\start-server.bat` 启动；
> - 或在 IDEA 的 Tomcat 配置里指定一个独立的 `CATALINA_BASE`（需要较熟的 Tomcat 配置经验）。

### 5. 断点调试

脚本方式启动 Tomcat 时，可以开启 JPDA：

```bat
set JPDA_ADDRESS=8000
set JPDA_TRANSPORT=dt_socket
call .tomcat\bin\catalina-local.bat jpda run
```

然后在 IDEA 新建 `Remote JVM Debug`，端口 `8000`，点击 Debug 连接。断点可以打在 Servlet、Service、DAO 中。

## 六、验证部署是否成功

### 1. 看控制台

成功时最后几行类似：

```text
信息 [main] org.apache.catalina.startup.Catalina.start [4616]毫秒后服务器启动
信息 [main] com.campus.trade.listener.AppContextListener.contextInitialized 校园二手交易平台后台启动成功。
```

### 2. 访问页面

```text
http://localhost:8080/campus-trade-admin/login
```

应看到左右分栏的登录页。

### 3. 登录

`admin / 123456`，应进入数据看板。

### 4. 检查数据库

```sql
USE campus_trade;
SELECT COUNT(*) FROM t_user;     -- 7
SELECT COUNT(*) FROM t_product;  -- 14
SELECT COUNT(*) FROM t_order;    -- 7
SELECT COUNT(*) FROM t_report;   -- 5
```

### 5. 检查静态资源

浏览器开发者工具 → Network → `admin.css`：

```text
Status: 200
Content-Type: text/css;charset=UTF-8
```

如果是 `text/html`，说明 `EncodingFilter` 又被加回了 `response.setContentType("text/html")`，需要删掉。

## 七、修改端口

端口配置在：

```text
scripts\tomcat-server.xml
```

找到：

```xml
<Connector connectionTimeout="20000" port="8080" protocol="HTTP/1.1" URIEncoding="UTF-8" redirectPort="8443"/>
```

把 `8080` 改成你需要的端口，例如 `8081`。然后重新运行：

```bat
scripts\start-server.bat
```

访问：

```text
http://localhost:8081/campus-trade-admin/
```

> 不要只改 `.tomcat\conf\server.xml`，因为 `init-tomcat.ps1` 每次启动都会用 `scripts\tomcat-server.xml` 覆盖它。

## 八、日志与排错

| 日志 | 位置 |
| --- | --- |
| 控制台 | `scripts\start-server.bat` 窗口 |
| Catalina | `.tomcat\logs\catalina.YYYY-MM-DD.log` |
| 访问日志 | `.tomcat\logs\localhost_access_log.YYYY-MM-DD.txt` |
| JSP 编译 | 控制台或 `catalina` 日志中的 `org.apache.jasper` |

### 常见问题

#### 1. `Address already in use: bind`

8080 被占用。查找：

```bat
netstat -ano | findstr :8080
```

结束占用进程，或改端口。

#### 2. `Access denied for user 'root'@'localhost'`

`db.properties` 密码不对，或 MySQL 服务没启动。检查：

```bat
net start MySQL80
```

#### 3. `Unknown database 'campus_trade'`

数据库不存在。启动项目会自动创建；也可以手动执行 `scripts\init-db.bat`。

#### 4. `Table 'campus_trade.t_user' doesn't exist`

数据库存在但表没建。执行 `scripts\init-db.bat`，或删除空库后重启项目。

#### 5. 404

访问地址必须包含 `/campus-trade-admin/`，不要只访问 `http://localhost:8080/`。

#### 6. 页面没样式

强制刷新 `Ctrl + F5`；检查 CSS 的 `Content-Type`；确认没有改回 `EncodingFilter` 的错误写法。

#### 7. `JRE_HOME environment variable is not defined correctly`

不要直接运行原 Tomcat 的 `catalina.bat`。用 `scripts\start-server.bat`，它会把 `JRE_HOME` 指向 JDK 25。

#### 8. `Struts2Demo` 启动失败

原 Tomcat 的 `conf/server.xml` 残留 Context。用项目 `.tomcat` 实例，或按第四节删除该 Context。

## 九、重置演示数据

### 方式 A：删库重启（最简单）

```bat
scripts\stop-server.bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe" -uroot -p123456 -e "DROP DATABASE IF EXISTS campus_trade;"
scripts\start-server.bat
```

项目启动时会重新建表并写入演示数据。

### 方式 B：重新执行 SQL

```bat
scripts\init-db.bat
```

> `data.sql` 使用 `INSERT IGNORE`，重复执行不会产生重复数据；但如果要恢复被修改过的状态，方式 A 更彻底。

## 十、备份与迁移

### 备份数据库

```bat
"C:\Program Files\MySQL\MySQL Server 8.0\bin\mysqldump.exe" -uroot -p123456 --default-character-set=utf8mb4 campus_trade > campus_trade_backup.sql
```

### 迁移到另一台电脑

1. 安装 JDK 17+、Tomcat 10.1+/11、MySQL 8+。
2. 复制整个 `campus-trade-admin` 项目目录。
3. 修改：
   - `scripts\start-server.bat` 里的 `CATALINA_HOME`、`JAVA_HOME`。
   - `scripts\init-tomcat.ps1` 的默认路径（或通过参数传入）。
   - `src/main/resources/db.properties` 的数据库账号密码。
4. 执行：
   ```bat
   scripts\build.bat
   scripts\start-server.bat
   ```
5. 如果目标机器没有 `.m2repo`，`build.bat` 会使用默认 Maven 仓库，需要联网下载依赖。

## 十一、生产部署提醒

本项目是课程设计，直接用于生产前至少要做：

- 修改 `admin` 默认密码，增加“修改密码”功能。
- 数据库不要用 `root`，创建最小权限用户。
- 增加 CSRF Token、登录失败限制、验证码。
- 增加图片上传的类型/大小校验。
- 使用 HTTPS。
- 增加日志轮转、监控、备份。
- 对举报、审核等敏感操作增加二次确认和更细的角色权限。
