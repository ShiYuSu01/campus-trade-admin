# 环境与版本矩阵

## 本机实测（2026-11-17）

| 组件 | 版本 | 说明 |
| --- | --- | --- |
| 操作系统 | Windows 11（10.0.26200）x64 | — |
| JDK | 25.0.4.1（Oracle HotSpot） | `pom.xml` 中 `maven.compiler.release=17` |
| Maven | 3.9.16 | 依赖走阿里云镜像 |
| Web 容器 | Apache Tomcat 11.0.22 | Jakarta EE 9+，Servlet 6.1 |
| 数据库 | MySQL 8.0.46 | 库 `campus_trade`，utf8mb4 |
| 连接池 | Druid 1.2.16 | `db.properties` 中 druid.* 参数 |
| 持久层工具 | commons-dbutils 1.7 | QueryRunner / BeanListHandler |
| 前端 | JSP + JSTL 3.0 + 原生 CSS/JS | 无前端框架 |
| 导出 | Apache POI 5.2.5 | 订单/举报 Excel 导出 |

## 版本兼容性

| 组合 | 结果 | 说明 |
| --- | --- | --- |
| Tomcat 11 + JDK 25 | ✅ 本项目实测通过 | 当前运行组合 |
| Tomcat 11 + JDK 17 | ✅ 预期可用 | release=17 字节码 |
| Tomcat 9 + 本项目 | ❌ 不可用 | 缺少 `jakarta.servlet`，会报 `NoClassDefFoundError` |
| 编译目标降到 11 | ❌ 失败 | 源码使用 switch 表达式、instanceof 模式匹配、文本块（Java 14+ 语法） |

## 与课程文档基线的差异

课程实验文档要求 JavaEE 8（`javax.servlet.*`）+ Tomcat 9 + JDK 8/11；本项目按老师指定的技术要求采用
Jakarta EE + Tomcat 11 + JDK 25。差异已在实验报告（实验四、实验八）中如实说明，不做包名迁移。
