# 常见问题补充（本机实测）

## 一、容器“启动即退出”，日志只写“子容器启动失败”

**现象**

```
严重 LifecycleBase.handleSubClassException 无法启动组件
  [StandardEngine[Catalina].StandardHost[localhost].StandardContext[/Struts2Demo]]
Caused by: java.lang.NoClassDefFoundError: org/apache/logging/log4j/Logger
```

**原因**：`conf/server.xml` 中残留了一条硬编码的 `<Context>`（指向旧项目的 `wtpwebapps` 目录），
该目录缺少 log4j，注解扫描阶段即抛异常；Tomcat 的 Host 启动是“全有或全无”，一个 Context 失败就整体中止。

**处理**：删除该 `<Context>` 行（或补齐其依赖），重启容器；日志应出现本项目的部署完成行。

## 二、启动日志里的 JDK 版本与 setenv.bat 不一致

**现象**：`setenv.bat` 指定 JDK 25，但日志打印 `Java虚拟机版本: 24.0.2`。

**原因**：`bin/setclasspath.bat` 首行被硬编码为 `set JRE_HOME=D:\jdk`，它会在 `setenv.bat` 之后执行并覆盖设置。

**处理**：注释该行，`setenv.bat` 中显式 `set "JAVA_HOME=..."` 并 `set "JRE_HOME="`，重启后版本一致。

## 三、健康检查返回 DEGRADED

**排查顺序**：① 看 `database.message`；② `netstat -ano | findstr :3306` 确认 MySQL 在监听；
③ 用 `db.properties` 里的账号手工 `mysql -u<user> -p` 登录；④ 确认 `CAMPUS_DB_*` 环境变量没有覆盖成错误值。

## 四、局域网/手机打不开

① 确认用「机器内网 IP:8080」而不是只写 IP；② Windows 防火墙需放行入站 8080；
③ 校园网/热点可能开启客户端隔离，需换同一路由器的设备测试。
