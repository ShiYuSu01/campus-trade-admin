## 四、检查中发现的“坑”（已处理）

这两点如果不处理，直接部署会失败：

### 1. 全局 Tomcat 的 `server.xml` 残留了 Struts2Demo Context

`D:\apache-tomcat-11.0.22\conf\server.xml` 末尾存在：

```xml
<Context docBase="D:\apache-tomcat-11.0.22\wtpwebapps\Struts2Demo"
         path="/Struts2Demo" reloadable="true" .../>
```

该目录缺少 log4j 依赖，Tomcat 启动时会报 `NoClassDefFoundError: org/apache/logging/log4j/Logger`，导致整个 Tomcat 启动失败。

**处理方式**：项目脚本不修改原 Tomcat，而是创建独立实例 `.tomcat`，使用 `scripts/tomcat-server.xml` 这份干净配置。

### 2. Tomcat 原启动脚本硬编码了 `JRE_HOME`

`D:\apache-tomcat-11.0.22\bin\catalina.bat` 与 `setclasspath.bat` 的**第 1 行**都是：

```bat
set JRE_HOME=D:\jdk
```

同时用户环境变量 `JRE_HOME` 指向的路径也可能无效，直接启动会报：

```text
The JRE_HOME environment variable is not defined correctly
```

**处理方式**：`scripts/init-tomcat.ps1` 会复制这两个脚本到 `.tomcat\bin`，删掉硬编码行，并让 `start-server.bat` 显式设置 `JAVA_HOME` 与 `JRE_HOME` 为 JDK 25。

## 五、数据库账号说明

本机 MySQL 的 `root` 密码为 `123456`。该密码来自你原有 `D:\jdk\shop\src\main\resources\db.properties` 的配置，并已实际登录验证。

项目默认配置：

```properties
jdbc.url=jdbc:mysql://localhost:3306/campus_trade?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&createDatabaseIfNotExist=true
jdbc.username=root
jdbc.password=123456
```

如果以后修改了 MySQL 密码，改 `src/main/resources/db.properties`，或在启动前设置：

```bat
set CAMPUS_DB_PASSWORD=新密码
```
