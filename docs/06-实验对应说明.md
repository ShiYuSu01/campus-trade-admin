# 实验对应说明（8 次实验 ↔ 仓库文件）

本文件用于把课程 8 次实验与仓库里的真实实现对应起来，方便评阅时逐项定位。

| 实验 | 实验要点 | 仓库中的对应实现 |
| --- | --- | --- |
| 实验一 | 环境搭建、Servlet 基础、WAR 部署 | 本项目的 war 结构与 `bin/setenv.bat`；Servlet 示例见 `servlet/DashboardServlet.java` |
| 实验二 | JSP/Servlet MVC + JDBC CRUD | `servlet/CategoryServlet.java`（列表/新增/改/删）→ `service/CategoryService.java` → `dao/CategoryDao.java` → `views/category/list.jsp` |
| 实验三 | 会话、过滤器、JSTL、分层重构 | `servlet/LoginServlet.java`、`filter/{EncodingFilter,AuthFilter,LayoutFilter}.java`、`web/BaseServlet.java`、`common/DbUtil.java`、全部 `views/**/*.jsp`（JSTL/EL） |
| 实验四 | AI 辅助、正式选题、MVP | 全项目；选题与 AI 记录写在实验报告中 |
| 实验五 | 核心业务闭环、首次部署 | `service/{ProductService,OrderService,ReportService}.java`（状态机规则）、`docs/04-部署运行手册.md`、`DEPLOY.md` |
| 实验六 | 部署搭档项目 | 搭档项目为纯前端（见 `docs/08-配对部署验证.md`） |
| 实验七 | 双向部署、部署加固 | `common/DbUtil.java`（`CAMPUS_DB_*` 环境变量覆盖）、`/health` 健康检查、`scripts/verify-deploy.ps1`、`DEPLOY.md` 故障分支 |
| 实验八 | GitHub 提交与总结 | 本仓库（README、docs、sql、scripts、源码分层） |

## 数据流一句话

浏览器 → Filter（编码/鉴权/布局）→ Servlet（收参与分派）→ Service（业务规则与事务）→ DAO（DbUtils 参数化）→ MySQL → JSP（JSTL 渲染）。
